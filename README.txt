AtlasFlow Portfolio — Fade Entry Package

Files:
- index.html — complete, self-contained portfolio site

How to use:
1. Upload index.html to the root of your GitHub/Vercel project.
2. It does not require a separate CSS, JavaScript, image, or assets folder.
3. The opening card fades into the portfolio on click.

The package includes:
- Centered white portfolio-entry card on a black background
- Two soft blue glow pulses on load
- Slight synchronized logo highlight
- 2px hover lift and stronger hover glow
- Full-card click target
- Fade transition into the main site
- Ada, Cal, Arc, and Animal Spirit showcase sections
- Elephant as the primary Animal Spirit archetype
- Responsive desktop and mobile layouts
